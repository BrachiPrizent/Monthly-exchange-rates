# Monthly Exchange Rates & Forecast Dashboard

This project displays the **monthly average USD/ILS exchange rate** with forecasted values. Data is fetched from the **Bank of Israel** and presented through an interactive **Angular** frontend.

---

## 🛠️ Technologies Used

- **MongoDB** – Database to store monthly exchange rates data.
- **Python** – Script to fetch real data from the Bank of Israel and update MongoDB.
- **Angular** – Frontend framework for displaying data in tables and charts.
- **PrimeNG** – UI components for tables, buttons, and charts.
- **Docker** – Containerize backend, database, and frontend for easy deployment.

---

## 🐳 Run the Project with Docker

The project is structured so that you can run everything using **Docker Compose**.

### Build and run the Docker

```bash
docker-compose up --build
```
